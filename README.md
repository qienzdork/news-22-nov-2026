# THE WORLD TODAY — Sunday 22 November 2026

A one-page newspaper front page summing up the world news of Sunday
22 November 2026, drawn procedurally with Pillow. No external assets.

Lead story: Bahrain says Iran struck a civilian industrial site late on
Saturday, as two oil tankers were hit in the Strait of Hormuz. Also
inside: COP31 talks run into overtime in Antalya, Mexico captures
"El Chapo Isidro", a magnitude 6.8 quake shakes Peru, and Alcaraz faces
Zverev in the ATP Finals title decider.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

or simply `python3 main.py` (writes `/output/entry.png`, or `$OUTPUT_PATH`
when set). The output is a deterministic 1024×1024 RGB PNG.
