# THE WORLD TODAY · Sunday 22 November 2026

A single-page newspaper front page for that Sunday, picturing the
day's world news in one image.

Front page: Bahrain blames Iran for a fire at a civilian industrial
site, two tankers are hit in the Strait of Hormuz, COP31 talks run
into overtime in Antalya, 'El Chapo Isidro' is captured in Mexico,
a 6.8 quake shakes Peru, and Alcaraz meets Zverev for the ATP
Finals title.

## Run

```sh
python3 main.py
```

`OUTPUT_PATH` picks the destination file directly. Otherwise the
front page lands at `$MAKEFUN_OUTPUT_DIR/entry.png`, or at
`/output/entry.png` when neither variable is set. Every run ships
the identical bytes.
